## 프로젝트 개요

### 목표

단순 소개 홈페이지를 **"시간이 지날수록 외부 콘텐츠와 내부 콘텐츠가 누적되며 브랜드 자산이 성장하는 자기확장형 복합문화공간 플랫폼"** 으로 리뉴얼한다.

| 구분 | 현재 | 목표 |
|------|------|------|
| 구조 | 소개형 정적 사이트 | 자기확장 플랫폼 |
| 데이터 | Mock 데이터 | 실제 DB + 외부 자동 수집 |
| 운영 | 수동 입력 | 자동 수집 + 운영자 큐레이션 |
| 확장성 | 제한적 | AI 큐레이션 구조까지 설계 |

### 플랫폼 6가지 성격

```
브랜드 사이트 + 공간 운영 사이트 + 프로그램 운영 사이트
+ 콘텐츠 플랫폼 + SNS 콘텐츠 허브 + 문화공간 SaaS 기반
```

### 기술 스택

| 레이어 | 기술 |
|--------|------|
| Frontend | Vite 7 + React 19 + TypeScript + TailwindCSS 3 |
| 상태 관리 | TanStack Query v5 |
| 폼 처리 | React Hook Form + Zod |
| Backend/BaaS | Supabase (PostgreSQL + Auth + Storage + Edge Functions) |
| 배포 | Vercel |

### 콘텐츠 수집 흐름

```
[수동 실행] 관리자 → AdminContentSourcesPage → runFetchForSource()
[자동 실행] Supabase Edge Function (cron) → runFetchAll()

    Platform Fetcher
    ├── rssFetcher      → DOMParser → NormalizedContent[]
    ├── youtubeFetcher  → YouTube Data API v3 → NormalizedContent[]
    ├── instagramFetcher → Instagram Graph API → NormalizedContent[]
    └── xFetcher        → X API v2 → NormalizedContent[]
              ↓
    aggregator.upsertBatch()
    [UNIQUE(source_id, external_id) → 중복 자동 방지]
              ↓
    external_contents 테이블
    [visibility_status: pending → 운영자 검토]
              ↓
    fetch_logs 테이블 [성공/실패/통계 기록]
```

## 외부 연동 구조

### RSS 수집

- **파일**: `src/services/fetchers/rssFetcher.ts`
- **방식**: allOrigins CORS 프록시 → DOMParser XML 파싱
- **지원**: 네이버 블로그, 티스토리, 워드프레스 (RSS 2.0 / Atom)
- **운영 권장**: Supabase Edge Function으로 이전 (CORS 문제 완전 해결)

```
RSS URL → CORS Proxy → XML → DOMParser → NormalizedContent[]
                                          ↓
                                    external_id = btoa(url)[:64]
                                    summary = HTML 제거, 300자
                                    thumbnail = enclosure or media:content
```

### YouTube 수집

- **파일**: `src/services/fetchers/youtubeFetcher.ts`
- **API**: YouTube Data API v3
- **방식**: 채널 ID → uploads 플레이리스트 → 영상 목록
- **할당량**: 하루 10,000 units (1시간 주기 1채널 ≈ 24 units)
- **주의**: API Key를 settings 테이블에 저장, Edge Function 전환 권장

### Instagram 수집

- **파일**: `src/services/fetchers/instagramFetcher.ts`
- **API**: Instagram Graph API (Business/Creator 계정 필요)
- **인증**: Long-lived Access Token (60일, 갱신 필요)
- **방식**: 최신 게시물 목록 조회, 이미지/캡션/링크 추출

### X 수집

- **파일**: `src/services/fetchers/xFetcher.ts`
- **API**: X API v2 Bearer Token
- **방식**: 타임라인 조회 (리트윗/답글 제외)
- **주의**: CORS 없음 → 반드시 서버 측(Edge Function)에서 실행
