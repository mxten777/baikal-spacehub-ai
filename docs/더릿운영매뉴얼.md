## 1. CMS 접속 및 대시보드

### 1-1. 로그인

- 주소: `/admin/login`
- 계정은 바이칼시스템즈에서 발급
- 로그아웃: 사이드바 하단 **로그아웃** 버튼

### 1-2. 사이드바 메뉴 (operator 기준)

```
대시보드
├── Spaces          공간 정보 관리
├── Programs        프로그램 등록·수정
├── Archive         아카이브 기록
├── Blog            블로그 작성·발행
├── Media           미디어 링크 관리
├── Inquiries       문의 처리
├── 예약 관리       예약 접수 확인 및 상태 처리
├── AI 사진 큐레이터  사진 업로드·큐레이션
└── 운영 정보       연락처·운영시간·SNS 수정
```

### 1-3. 대시보드 카드

| 카드     | 표시 내용                  |
| -------- | -------------------------- |
| 공간     | 등록된 공간 수             |
| 프로그램 | 진행 중 / 전체 프로그램 수 |
| 블로그   | 발행된 포스트 수           |
| 문의     | 미처리 문의 수 (신규)      |

| 필드            | 필수 | 설명                                        |
| --------------- | ---- | ------------------------------------------- |
| 이름            | ✅   | 한국어 공간 이름                            |
| 영문 이름       |      | 영문 이름                                   |

## 7. 문의 관리

**메뉴**: Inquiries (`/admin/inquiries`)

### 상태 흐름

```
pending (신규 접수)
  → reviewing (검토 중)
    → resolved (처리 완료)
      → closed (종료)
```

### 처리 절차

1. `pending` 문의 확인
2. 클릭 → 이름·연락처·메시지 내용 확인
3. 이메일 또는 전화로 응답
4. 상태를 `reviewing` → `resolved`로 순차 변경
5. 처리 내용을 메모 필드에 기록 (권장)

### 확인 가능한 정보

| 필드      | 설명                       |
| --------- | -------------------------- |
| 이름      | 문의자 이름                |
| 이메일    | 연락 이메일 (선택 제출)    |
| 전화번호  | 연락처 (선택 제출)         |
| 예상 인원 | 공간 대관 예상 참가 인원   |
| 희망 날짜 | 요청 날짜                  |
| 메시지    | 상세 문의 내용             |
| 접수 일시 | 자동 기록                  |

## 8. 예약 관리

**메뉴**: 예약 관리 (`/admin/reservations`)

웹사이트 **Book a Space** 페이지에서 접수된 예약 요청을 관리합니다.

### 상태 흐름

```
new (신규 접수)
  → consulting (상담 중)
    → quote_sent (견적 발송)
      → confirmed (확정)
        → completed (완료)
        → cancelled (취소)
```

### 처리 절차

1. `new` 상태 예약 확인 (접수 시 즉시 알림 없음 — 주기적으로 확인 필요)
2. 예약 행 클릭 → 세부 내용 확인
3. 고객 전화/이메일 연락 → 상태를 `consulting`으로 변경
4. 견적 전달 후 → `quote_sent`
5. 계약 완료 → `confirmed`
6. 행사 종료 후 → `completed`

### 확인 가능한 정보

| 필드          | 설명                                             |
| ------------- | ------------------------------------------------ |
| 행사 유형     | 전시·공연·워크숍·브랜드행사·기업행사·촬영·웨딩·모임·공간상담 |
| 희망 날짜     | 고객이 입력한 날짜 (없으면 날짜 유동적)          |
| 예상 인원     | 숫자 (없으면 미입력)                             |
| 예산 범위     | 고객 선택 구간                                   |
| 추천 공간     | 시스템이 자동 추천한 공간명                      |
| 선택 공간     | 고객이 최종 선택한 공간 ID                       |
| 이름·전화·이메일 | 고객 연락처                                   |
| 회사/단체명   | 선택 입력                                        |
| 추가 요청사항 | 고객 메모                                        |
| 접수 일시     | 자동 기록                                        |

> ⚠️ **공간 상담** 유형은 날짜·인원·공간 선택 없이 연락처만 있습니다. 전화 상담 먼저 진행하세요.

## 9. AI 사진 큐레이터

**메뉴**: AI 사진 큐레이터 (`/admin/photo-curator`)

웹사이트 각 페이지에 노출되는 사진을 업로드하고 큐레이션합니다.  
프로젝트 생성·구조 설계는 바이칼시스템즈가 담당하며, 더릿 운영자는 사진 업로드와 큐레이션만 수행합니다.

### 카테고리 × 단계 구조

| 카테고리         | 웹사이트 노출 위치              |
| ---------------- | ------------------------------- |
| `main`           | 홈 히어로 슬라이드 배경         |
| `wedding`        | 공간 상세 — 웨딩 섹션           |
| `space`          | 공간 목록 및 상세 페이지        |
| `food_beverage`  | F&B 관련 섹션                   |
| `archive`        | 아카이브 페이지                 |
| `contact`        | 문의 페이지 배경                |
| `about`          | About 페이지                    |

| 단계       | 의미                                  |
| ---------- | ------------------------------------- |
| `source`   | 원본 파일 (촬영 원본)                 |
| `selected` | 선별 완료 (편집 전)                   |
| `edited`   | 편집 완료                             |
| `web`      | **웹 최적화 완료 → 사이트에 노출됨**  |
| `pdf`      | 인쇄용 고해상도                       |

> 💡 **웹사이트에 실제로 노출되는 사진은 `web` 단계 사진**입니다.  
> 사진을 교체하려면 기존 사진을 삭제하고 새 사진을 `web` 단계로 업로드하세요.

### 사진 업로드 방법

1. AI 사진 큐레이터 메뉴 진입
2. 프로젝트 선택 (바이칼시스템즈가 생성한 프로젝트)
3. 업로드할 카테고리와 단계의 셀에서 `↑` 아이콘 클릭
4. 파일 선택 (JPG, PNG, WebP · 최대 10MB/파일 · 복수 선택 가능)
5. 업로드 완료 후 배지 숫자 자동 갱신 확인

### 사진 삭제 방법

1. 해당 셀 배지 클릭 → 슬라이드 패널 열림
2. 삭제할 사진 썸네일의 `✕` 아이콘 클릭
3. 확인 → 즉시 삭제 (복구 불가)

### 메타데이터 편집

슬라이드 패널에서 사진 썸네일 클릭:

| 필드  | 설명                            |
| ----- | ------------------------------- |
| 제목  | 사진 제목 (선택)                |
| 설명  | 사진 설명 텍스트 (선택)         |
| 태그  | Enter 또는 쉼표로 추가          |
| 메모  | 내부 메모 (공개 안 됨)          |

### 권한 범위 (operator)

| 기능                   | 가능 여부 |
| ---------------------- | --------- |
| 사진 업로드            | ✅        |
| 사진 삭제              | ✅        |
| 메타데이터 편집        | ✅        |
| 프로젝트 생성·수정     | ❌ (바이칼 전용) |
| 프로젝트 구조 변경     | ❌ (바이칼 전용) |
