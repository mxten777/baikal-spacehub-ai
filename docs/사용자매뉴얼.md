## 1. The Lit 소개

**The Lit(더릿)**은 서울 마포구 연남동에 위치한 복합문화공간입니다.

> *"빛이 가득한 공간에서 예술과 일상이 만나는 곳"*

### 1-1. 공간 철학

The Lit은 단순한 공간 임대를 넘어, 예술가·기획자·관객이 함께 만들어가는 문화 생태계를 지향합니다. 전시, 공연, 강연, 워크숍이 일상적으로 공존하는 이 공간에서 여러분만의 특별한 경험을 찾아보세요.

### 1-2. 주요 서비스

| 서비스 | 설명 |
|--------|------|
| **공간 대관** | 카페, 가든, 스튜디오, 스토리지 홀 대관 |
| **문화 프로그램** | 전시·공연·강연·워크숍·이벤트 |
| **아카이브** | 지난 프로그램 기록 열람 |
| **블로그** | 큐레이션 콘텐츠 |
| **미디어** | YouTube·Instagram·X 통합 피드 |

## 2. 웹사이트 구성

### 2-1. 주요 메뉴

웹사이트 상단 네비게이션 메뉴에서 각 섹션으로 이동할 수 있습니다.

| 메뉴 | URL | 내용 |
|------|-----|------|
| **홈** | `/` | 전체 소개, 예정 프로그램, 미디어 |
| **공간** | `/spaces` | 대관 가능한 공간 소개 |
| **프로그램** | `/programs` | 예정·진행 중 문화 프로그램 |
| **아카이브** | `/archive` | 지난 프로그램 기록 |
| **블로그** | `/blog` | 큐레이션 콘텐츠 |
| **미디어** | `/media` | 영상 및 SNS 피드 |
| **어바웃** | `/about` | The Lit 이야기·팀·비전 |
| **문의** | `/contact` | 공간 대관·일반 문의 |

### 2-2. 모바일 이용

- 스마트폰과 태블릿에서도 동일하게 이용 가능합니다
- 모바일에서는 우측 상단 **햄버거 메뉴(☰)** 를 눌러 메뉴를 열 수 있습니다
- 모든 이미지와 콘텐츠는 화면 크기에 맞게 자동 최적화됩니다

## 3. 공간 안내 이용하기

### 3-1. 공간 목록 보기

**메뉴 > 공간** 클릭 시 The Lit의 모든 공간이 카드 형태로 표시됩니다.

각 카드에서 확인 가능한 정보:
- 공간 이름 및 카테고리
- 대표 이미지
- 수용 인원
- 시간당 대관료 (기본 안내)
- 예약 가능 여부

### 3-2. 공간 상세 정보 보기

1. 원하는 공간 카드 클릭
2. 상세 페이지에서 확인 가능한 내용:

| 섹션 | 내용 |
|------|------|
| **이미지 갤러리** | 공간 여러 각도의 사진 슬라이드 |
| **기본 정보** | 면적, 수용인원, 시설 특징 |
| **대관 요금** | 시간대별 기본 요금 안내 |
| **시설 목록** | 제공 시설/장비 태그 |
| **대관 문의 버튼** | 클릭 시 문의 페이지로 이동 |

### 3-3. 공간 종류

| 공간 | 특징 | 적합한 용도 |
|------|------|------------|
| **카페** | 따뜻한 인테리어, 음료 제공 가능 | 소모임, 간담회, 아트마켓 |
| **가든** | 자연광 가득한 야외형 공간 | 파티, 촬영, 야외 행사 |
| **스튜디오** | 전문 조명·음향 시설 | 공연, 워크숍, 강연, 촬영 |
| **스토리지 홀** | 넓은 오픈 공간 | 전시, 대형 이벤트, 팝업 |

## 4. 문화 프로그램 신청

### 4-1. 프로그램 목록 보기

**메뉴 > 프로그램** 에서 현재 예정·진행 중인 모든 프로그램을 볼 수 있습니다.

**필터 기능:**
- **카테고리 필터**: 전시 / 공연 / 강연 / 워크숍 / 이벤트
- **상태 필터**: 예정 / 진행 중 / 종료됨

### 4-2. 프로그램 상세 보기

1. 관심 있는 프로그램 카드 클릭
2. 상세 페이지에서 확인 가능:

| 항목 | 설명 |
|------|------|
| **제목 및 카테고리** | 프로그램 제목과 분류 |
| **일정** | 시작·종료 날짜 |
| **요금** | 무료 / 유료 금액 |
| **상세 설명** | 프로그램 소개 전문 |
| **신청 버튼** | 외부 신청 페이지 이동 |

### 4-3. 프로그램 신청 방법

1. 원하는 프로그램 상세 페이지 접속
2. **신청하기** 버튼 클릭
3. 연결되는 외부 페이지(네이버폼, 구글폼, 티켓링크 등)에서 신청 완료

> 신청 방법은 프로그램마다 다를 수 있습니다. 상세 페이지의 안내를 따라주세요.

### 4-4. 프로그램 상태 안내

| 상태 배지 | 의미 |
|----------|------|
| 🟢 **예정** | 곧 시작 예정, 신청 가능할 수 있음 |
| 🔵 **진행 중** | 현재 진행 중 |
| ⚫ **종료** | 이미 마감 또는 종료됨 |
| 🔴 **취소** | 취소된 프로그램 |

## 5. 아카이브 둘러보기

### 5-1. 아카이브란?

The Lit에서 지금까지 열렸던 모든 프로그램의 기록을 보관하는 섹션입니다.  
과거의 전시, 공연, 워크숍 등을 사진과 함께 되돌아볼 수 있습니다.

### 5-2. 아카이브 이용 방법

1. **메뉴 > 아카이브** 접속
2. 카드 형태로 표시되는 과거 프로그램 목록 확인
3. 각 카드에서 확인 가능한 정보:
   - 프로그램 제목
   - 카테고리 (전시/공연/워크숍 등)
   - 개최 연도 및 기간
   - 대표 이미지

### 5-3. 필터 및 검색

- **카테고리별 필터**: 전시, 공연, 워크숍, 이벤트, 강연
- **연도별 필터**: 개최 연도 선택하여 필터링

## 6. 블로그 읽기

### 6-1. 블로그 콘텐츠

The Lit 블로그에는 다음과 같은 콘텐츠가 게재됩니다:

- 전시·공연 관람 후기 및 리뷰
- 예술가 인터뷰
- 공간 활용 아이디어
- 문화 트렌드 큐레이션
- The Lit의 이면 이야기 (Behind the Scene)

### 6-2. 블로그 이용 방법

1. **메뉴 > 블로그** 접속
2. 포스트 목록 확인 (최신순)
3. **카테고리 탭**으로 원하는 분야 필터링
4. 포스트 카드 클릭 → 전체 내용 읽기

### 6-3. 블로그 공유

포스트 상세 페이지에서:
- 브라우저 주소창의 URL 복사 → 지인에게 공유
- SNS 공유 버튼 (제공 시) 활용

## 8. 공간 대관 문의

### 8-1. 문의 방법

**메뉴 > 문의** 페이지에서 직접 문의를 보낼 수 있습니다.

또는 이메일·전화로도 문의 가능합니다:
- 📧 이메일: hello@thelit.kr
- 📞 전화: 02-0000-0000
- 📍 방문: 서울특별시 마포구 연남동 000-00

### 8-2. 온라인 문의 작성 방법

1. **메뉴 > 문의** 접속
2. 문의 유형 선택:

| 유형 | 선택 기준 |
|------|----------|
| **공간 대관** | 공간 임대를 하고 싶을 때 |
| **프로그램 문의** | 진행 중인 프로그램에 대해 물어볼 때 |
| **협업 제안** | 함께 이벤트나 전시를 기획하고 싶을 때 |
| **기타** | 그 외 일반 문의 |

3. 정보 입력:

| 항목 | 필수 여부 | 설명 |
|------|----------|------|
| 이름 | ✅ 필수 | 문의자 성함 |
| 이메일 | 선택 | 회신 받을 이메일 |
| 전화번호 | 선택 | 연락처 |
| 예상 인원 | 선택 | 공간 대관 시 참가 예상 인원 |
| 희망 날짜 | 선택 | 대관 또는 방문 희망 날짜 |
| 메시지 | ✅ 필수 | 상세 문의 내용 |

4. **문의 보내기** 버튼 클릭

### 8-3. 문의 후 처리 과정

```
고객 문의 접수
    ↓ (즉시 자동 확인)
The Lit 운영팀 검토 (영업일 1-2일 내)
    ↓
이메일 또는 전화 회신
    ↓
세부 조율 (일정, 가격, 시설 확인)
    ↓
대관 계약 체결
```

### 8-4. 대관 문의 시 준비 정보

원활한 상담을 위해 다음 정보를 준비해 주시면 더 빠른 답변이 가능합니다:

- **행사 성격**: 어떤 종류의 행사인지 (전시, 파티, 강연 등)
- **예상 인원**: 최대 참가 예정 인원
- **희망 날짜**: 가능한 여러 날짜 후보
- **사용 시간**: 행사 시작·종료 시간 + 셋업/철수 시간
- **필요 시설**: 음향, 조명, 빔프로젝터 등

## 9. 자주 묻는 질문 (FAQ)

### 공간 대관

**Q. 최소 대관 시간이 있나요?**  
A. 기본 최소 대관 시간은 2시간입니다. 공간 및 행사 성격에 따라 다를 수 있으니 문의 시 확인해 주세요.

**Q. 셋업/철수 시간도 대관 시간에 포함되나요?**  
A. 네, 셋업 및 철수 시간을 포함한 전체 점유 시간이 대관 시간으로 계산됩니다. 여유 있게 시간을 확보해 주세요.

**Q. 대관 시 취소·환불 정책은 어떻게 되나요?**  
A. 계약 후 취소 시 취소 시점에 따라 환불 정책이 다릅니다. 계약 시 상세 안내를 받으시거나 별도 문의해 주세요.

**Q. 케이터링(음식·음료)을 직접 가져올 수 있나요?**  
A. 공간에 따라 외부 반입 가능 여부가 다릅니다. 대관 문의 시 확인해 주세요.

**Q. 주차가 가능한가요?**  
A. 전용 주차장은 없으나, 인근 공영주차장을 이용하실 수 있습니다 (도보 5분). 대중교통 이용을 권장합니다.

---

### 프로그램

**Q. 프로그램 신청은 어떻게 하나요?**  
A. 프로그램 상세 페이지의 **신청하기** 버튼을 클릭하면 해당 신청 페이지로 연결됩니다.

**Q. 프로그램 취소·환불은 어떻게 하나요?**  
A. 각 프로그램별 취소 정책이 다릅니다. 신청 페이지나 문의 폼을 통해 문의해 주세요.

**Q. 유아/어린이도 참여 가능한가요?**  
A. 프로그램마다 연령 제한이 다릅니다. 상세 페이지의 참여 조건을 확인해 주세요.

---

### 일반

**Q. 일반 방문 (카페 이용 등)도 가능한가요?**  
A. 네, 별도 예약 없이 운영 시간 내 방문하실 수 있습니다. 단, 행사 대관 중에는 입장이 제한될 수 있습니다.

**Q. 운영 시간은 어떻게 되나요?**  
A. 화요일~일요일 11:00~21:00 운영, 매주 월요일 휴무입니다.  
(특별 행사 기간에는 운영 시간이 변경될 수 있습니다.)

**Q. 반려동물을 데리고 올 수 있나요?**  
A. 현재 반려동물 동반 입장은 불가합니다. 양해 부탁드립니다.

**Q. 사진 촬영이 가능한가요?**  
A. 일반 방문 시 개인 촬영은 가능합니다. 단, 전시 작품 촬영 시 작가의 의사에 따라 제한될 수 있습니다.  
상업적 목적의 촬영은 사전 허가가 필요합니다.

**Q. 뉴스레터를 구독하고 싶어요.**  
A. 웹사이트 하단 또는 문의 페이지에서 구독 신청이 가능합니다.
