## 1. 제안 개요

### 1-1. 제안 배경

The Lit은 서울 마포구 연남동에 위치한 복합문화공간으로, 공간 대관·문화 프로그램·커뮤니티를 통합한 디지털 플랫폼이 필요합니다. 본 제안은 **기존에 완성도 높게 개발된 복합문화공간 전용 플랫폼(Baikal SpaceHub AI)**을 The Lit 브랜드에 맞게 커스터마이징하는 방식으로 진행합니다.

신규 개발 대비 **비용 60~70% 절감**, **납기 단축**, **검증된 기능 완성도**라는 세 가지 이점을 제공합니다.

### 1-2. 핵심 제안 가치

| 항목            | 내용                                          |
| --------------- | --------------------------------------------- |
| **방식**        | 기개발 플랫폼 커스터마이징 (신규 개발 아님)   |
| **기간**        | 착수 후 **4주** 내 1차 오픈 가능              |
| **비용**        | 신규 개발 대비 약 65% 절감                    |
| **기능 완성도** | 어드민 CMS 포함 전 기능 즉시 사용 가능        |
| **확장성**      | 추후 예약·결제·멤버십 시스템 단계적 추가 가능 |

## 5. 작업 일정

### 5-1. Phase 1 전체 일정 (4주)

```
Week 1 │ 준비 및 환경 설정
       │ ├─ Supabase 프로젝트 생성 (The Lit 전용)
       │ ├─ 데이터베이스 마이그레이션 실행
       │ ├─ Vercel 배포 환경 구성
       │ └─ 브랜드 자료 수집 (로고, 폰트, 컬러, 사진)

Week 2 │ 브랜드 아이덴티티 적용
       │ ├─ 컬러·타이포그래피 시스템 교체
       │ ├─ 로고·파비콘 삽입
       │ ├─ 홈 Hero 및 각 페이지 카피 교체
       │ └─ thelit.kr 도메인 연결 및 테스트

Week 3 │ 콘텐츠 세팅 및 기능 검증
       │ ├─ 공간 4종 데이터 등록 (사진·설명·요금)
       │ ├─ 멤버십·프로그램 정보 입력
       │ ├─ 문의 수신 이메일 연결 및 테스트
       │ └─ 전 페이지 크로스 브라우저 QA

Week 4 │ 최종 검수 및 오픈
       │ ├─ SEO 최종 점검 (Sitemap·robots·OG)
       │ ├─ 모바일·데스크톱 최종 QA
       │ ├─ 어드민 사용 교육 (1시간)
       │ └─ 정식 오픈 및 인수인계
```
