# THE LIT 홈페이지 운영 매뉴얼

> 작성 기준: 2026년 8월 | 관리자 URL: https://thelit.kr/admin

---

## 1. 운영 흐름

THE LIT 홈페이지는 아래 순서로 운영됩니다.

```
SNS 업로드  →  관리자에서 자동 수집  →  운영자 검토  →  홈페이지 공개
```

운영자는 콘텐츠를 직접 만들지 않습니다.  
**확인 후 공개 여부만 결정합니다.**

## 4. 외부 콘텐츠 운영 (핵심 업무)

### 운영 순서

```
① YouTube / Instagram / 블로그에 업로드
        ↓
② 홈페이지 관리자에서 자동 수집
        ↓
③ [외부 콘텐츠] 메뉴에서 내용 확인
        ↓
④ 공개(Published) 또는 대표 노출(Featured) 선택
        ↓
⑤ 홈페이지에 자동 반영
```

### 공개 상태

| 상태                     | 의미                            |
| ------------------------ | ------------------------------- |
| **대기 (Pending)**       | 수집되었으나 미공개 — 기본 상태 |
| **공개 (Published)**     | 홈페이지에 노출                 |
| **대표 노출 (Featured)** | 홈페이지 상단·메인에 강조 노출  |
| **비공개 (Hidden)**      | 부적절하거나 오류 콘텐츠에 사용 |

### ⚠️ 주의

> YouTube에 영상을 올렸다고 바로 홈페이지에 공개되지 않습니다.  
> **반드시 외부 콘텐츠 메뉴에서 검토 후 '공개'를 선택하세요.**

---

## 5. SNS 운영

아래 플랫폼에 업로드하면 자동으로 수집됩니다.

| 플랫폼       | 수집 방식                 |
| ------------ | ------------------------- |
| YouTube      | 채널 업로드 시 자동 수집  |
| Instagram    | 피드 업로드 시 자동 수집  |
| 블로그 (RSS) | RSS 피드를 통해 자동 수집 |

수집까지 수 분~1시간이 소요될 수 있습니다.  
즉시 반영이 필요하면 외부 콘텐츠 화면에서 **[새로고침]** 버튼을 눌러주세요.

---

## 6. 문의 및 예약 관리

| 메뉴          | 확인 방법                                         |
| ------------- | ------------------------------------------------- |
| **문의 관리** | [문의 관리] 클릭 → 새 문의 확인 → 담당자에게 전달 |
| **예약 관리** | [예약 관리] 클릭 → 신규 신청 확인 → 고객에게 연락 |

---

## 7. 운영 시 주의사항

아래 항목은 **절대 변경하지 마세요.**

- **콘텐츠 소스** 설정 (YouTube 채널 주소, Instagram 계정 등)
- **시스템 설정**

변경 시 전체 콘텐츠 수집이 중단될 수 있습니다.  
변경이 필요하면 **반드시 BAIKAL에 먼저 문의하세요.**

---

## 8. 문제가 발생하면

| 상황                   | 조치                                       |
| ---------------------- | ------------------------------------------ |
| 콘텐츠가 수집되지 않음 | [새로고침] 클릭 → 해결 안 되면 BAIKAL 문의 |
| 로그인이 안 됨         | BAIKAL에 비밀번호 초기화 요청              |
| 화면이 비어 있음       | 페이지 새로고침 → 해결 안 되면 BAIKAL 문의 |
| 그 외 모든 오류        | BAIKAL에 화면 캡처와 함께 문의             |

> **시스템은 BAIKAL이 관리합니다. 운영자는 콘텐츠만 관리합니다.**
