## 1. 사업 개요

### 1-1. 사업 개요 요약

| 항목            | 내용                                                   |
| --------------- | ------------------------------------------------------ |
| **사업명**      | The Lit — 복합문화공간 플랫폼                          |
| **영문명**      | The Lit Cultural Space Platform                        |
| **소재지**      | 서울특별시 마포구 연남동                               |
| **사업 형태**   | 공간 대관 + 문화 프로그램 기획·운영 + 디지털 플랫폼    |
| **대표 서비스** | 공간 임대, 문화 프로그램 운영, 커뮤니티 허브           |
| **목표 고객**   | 2030 문화 소비층, 기업/단체 이벤트 기획자, 독립 예술가 |
| **핵심 가치**   | 예술·일상·공간의 통합 경험                             |

### 1-2. 사업 비전 및 미션

**비전 (Vision)**

> 서울의 문화 허브로서, 예술가와 관객이 일상에서 만나는 지속 가능한 복합문화공간 생태계 구축

**미션 (Mission)**

> 공간의 경계를 허물고, 누구나 예술을 통해 일상을 풍요롭게 누릴 수 있는 접근성 높은 문화 플랫폼 제공

**핵심 가치**

| 가치       | 설명                                           |
| ---------- | ---------------------------------------------- |
| **개방성** | 장르·형식에 얽매이지 않는 열린 예술 공간       |
| **지속성** | 예술가와 공간이 함께 성장하는 지속 가능 생태계 |
| **연결성** | 예술가·기획자·관객·기업을 잇는 플랫폼 역할     |
| **접근성** | 가격·형식의 문턱을 낮춘 문화 민주화            |

### 1-3. 사업 배경

서울 마포구 연남동은 홍대 상권과 인접하여 2030 문화 소비층이 밀집한 지역입니다. 그러나 독립 예술가들이 합리적인 비용으로 사용할 수 있는 전문 복합문화공간은 여전히 부족합니다. The Lit은 이 공백을 채우는 동시에, 디지털 플랫폼과 물리적 공간을 통합하여 온·오프라인 문화 커뮤니티를 형성하고자 합니다.
